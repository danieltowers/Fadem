# Fadem 1.0.0

The first release of Fadem, a music player for Windows that lets you set the transition between
any two tracks. Most players use one crossfade setting for the whole library. In Fadem you choose,
for each pair of tracks, where the outgoing track fades, where the incoming one starts, and how
long each fade lasts.

## Install

`FademSetup-1.0.0.exe` installs the standalone app, the MusicBee plugin, or both. It installs for
your user only, so there's no admin prompt, and the app needs nothing else installed. You need
64-bit Windows, and the plugin needs the 32-bit MusicBee 3 (tested on 3.6). Close MusicBee before
you install the plugin; the installer waits until you do.

The installer isn't code-signed yet, so Windows may warn that it comes from an unknown publisher.
Click **More info**, then **Run anyway**.

Setup steps for both hosts are in the
[README](https://github.com/danieltowers/Fadem/blob/v1.0.0/README.md#install).

## What's in it

- A transition for every ordered pair of tracks. You set it once and it plays wherever that pair
  meets. A playlist can override any part of it.
- A transition editor, opened from the button between two rows. **Capture** sets a point to where
  the playhead is now, and the nudge buttons move it by 0.1 s or 1 s.
- **Preview**, which plays your edit from 5 s before the transition and leaves your place in the
  queue alone.
- Three fade curves: equal-power, linear and S-curve.
- Fade marks on the seek bar, which you can drag.
- A **Transitions** dialog that lists every transition one track is part of.
- Sections, which group rows in a playlist under a coloured header.
- WASAPI shared, WASAPI exclusive and WaveOut output, with ReplayGain.
- A MusicBee plugin with a sidebar panel, an optional Now Playing view, and an **Add to Fadem's
  open playlist** item on MusicBee's right-click menu.
- MusicBee's skin colours, dark or light, in both the plugin and the standalone app.

## Supported audio

Every point you set plays within 1 ms of where you put it. Fadem checks each file when you add it,
and turns away any file it can't play that exactly. It plays WAV, FLAC, MP3 (CBR, or VBR with a
Xing header), WMA 9 Standard and WMA 9 Lossless. The rates and depths for each format are in
[supported-audio.md](https://github.com/danieltowers/Fadem/blob/v1.0.0/docs/supported-audio.md).

## Known limits

- Fadem runs on Windows only, and the plugin needs the 32-bit MusicBee.
- The standalone app plays on the default audio device only.
- Transitions are tied to file paths, so they don't follow a file you move or rename.
- Cue sheets and M4A files (AAC or ALAC) aren't supported.
- The plugin runs beside MusicBee's player, not inside it, with its own queue and timeline.
